## 📋 Deskripsi Proyek

Aplikasi web landing page responsif bertema teknologi modern yang dibangun menggunakan **React JS** dan **Bootstrap 5**. Proyek ini dikembangkan secara kustom dan orisinal untuk memenuhi tugas **Pertemuan 1 React JS** dengan ketentuan:

1. **Halaman Home (Beranda):**
   - **Header / Navbar:** Sticky bar dengan branding *NexSphere*, menu navigasi responsif (*Home, Team, Contact*), dan tombol aksi *Login* & *Sign-up* dengan modal popup interaktif.
   - **Hero Section:** Salam pembuka *"Selamat Datang di Website Kami"*, deskripsi platform yang informatif, tombol call-to-action (*Jelajahi Fitur* & *Konsultasi*), banner laptop modern, serta indikator ringkas (*100% Responsif*, *< 0.5s Render*, dll).
   - **Keunggulan Layanan:** 3 kolom kartu fitur modern (*Responsif & Adaptif*, *Cepat & Ringan*, *Desain Modern & Rapi*) dengan ikon berwarna, subjudul, dan efek hover.

2. **Halaman Team (Tim Pengembang):**
   - 3 kartu profil tim profesional (*Fadhel Yihua Rafael* sebagai Lead Frontend Engineer, *Nadine Aurelia* sebagai UI/UX Designer, dan *Rendy Pratama* sebagai Backend Engineer) dengan foto profil bulat elevated, badge keahlian, peran, deskripsi tugas, dan ikon sosial media.

3. **Halaman Contact (Hubungi Kami):**
   - Tata letak split card yang elegan: sisi kiri memuat informasi langsung (lokasi kantor/kampus, email resmi, waktu respon, sosial media), dan sisi kanan memuat formulir interaktif lengkap (*Nama Lengkap*, *Alamat Email*, *Topik Keperluan*, *Isi Pesan*, persetujuan checkbox, tombol submit dengan animasi loading dan alert konfirmasi sukses).

4. **Footer:**
   - Tema gelap modern dengan deskripsi platform, navigasi cepat (*Home, Team, Contact*), rincian teknologi yang digunakan, serta informasi hak cipta.

## 🚀 Cara Menjalankan Proyek Secara Lokal

1. Buka terminal di folder proyek ini:
   ```bash
   cd "c:\Users\fadhe\Documents\SEMESTER 5\PERTEMUAN REACT JS\PERTEMUAN 1 REACT"
   ```

2. Jalankan development server:
   ```bash
   npm run dev
   ```

3. Buka browser di alamat:
   ```
   http://localhost:5173/
   ```

## 📤 Panduan Push ke GitHub (Untuk Anda Lakukan Sendiri)

1. Buat repository baru di akun GitHub Anda (misal: `pertemuan-1-react`).
2. Di terminal VS Code, jalankan perintah berikut:
   ```bash

   git commit -m "feat: complete Tugas Pertemuan 1 React JS with unique NexSphere theme"
   git remote add origin https://github.com/FadhelYihuaRafael/pertemuan-1-react.git
   git push -u origin main
   ```

3. Buka repository GitHub Anda, masuk ke **Settings** > **Collaborators** > **Add people**, lalu undang username mentor Anda.
